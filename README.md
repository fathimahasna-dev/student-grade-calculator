## Student Grade Calculator

A beginner-friendly Python project that calculates a student's total marks, average, grade, and pass/fail result. This project helps beginners understand how to use user input, variables, arithmetic operations, and conditional statements in Python.

## Project Overview

The Student Grade Calculator asks the user to enter a student's name and marks for five subjects. It then calculates the total marks and average, determines the student's grade, and displays whether the student has passed or failed.

This project is suitable for students who are learning Python and want to build a simple real-world application.

## Features

- Enter student name
- Enter marks for 5 subjects
- Calculate total marks
- Calculate average
- Display grade (A, B, C, D, F)
- Display Pass or Fail result
- Easy-to-understand Python code

##  How to Run

1. Install Python.
2. Download or clone this project.
3. Open the project in VS Code.
4. Run the program:

bash
python student_grade_calculator.py


5. Enter:
   - Student name
   - Marks for 5 subjects

6. The program will display:
   - Total Marks
   - Average
   - Grade
   - Pass/Fail Result
